# Hyper_gendaqi
Hyper is a powerful typing tool that combines the strengths of Heiwu, Pain, Tianyu, and Xiaoji's online posting typing tools.
It supports both Windows and macOS, and is the strongest typing tool for Mac that supports bubbling, posting, and group selection!
The software must be used in conjunction with the `resources` folder; otherwise, features will be incomplete, and the Mac version will experience lag!!! Join the group to learn how to use it and download the `resources` files.
Communication Group: 604836383

## Free Version Benefits
- Text cleaning function: Removes strange symbols, hyperlinks, Japanese, and Korean characters.
- Custom regex cleaning function.
- Practice tool.
- Local article manager.
- Basic loading and posting functions.
- Text collection tool: Save favorite paragraphs to continue typing them later.

## Paid Version
- Disguise/Masking features.
- Network difficulty level-based posting function.
- Server-side book downloading and typing function.

## Software Usage Instructions
To use this software, you need to download the `resources` compressed package from the QQ group and extract it into the same directory as the software; otherwise, you will be using an incomplete version.
